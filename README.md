# Cafe Website

プログラミングスクール「ZeroPlus」でのチーム開発課題として制作した、
架空のカフェサイトです。

講師がクライアント役となり、
要件定義からデザイン・コーディングまでを、
7人チームで進めました。

HTML / CSS / JavaScript を用いて、
カフェの雰囲気や世界観が伝わるWebサイトを目指して制作しました。

---

## 制作背景

ZeroPlusでのチーム開発課題として、
実際のWeb制作案件を意識しながら制作を行いました。

本プロジェクトでは、

* 要件定義
* デザイン設計
* コーディング
* チーム開発

までを経験し、
実務を意識した制作フローで進行しました。

また、講師がクライアント役となり、

* ヒアリング
* 要件整理
* デザイン調整

なども行いました。

---

## 主な機能

### レスポンシブ対応

スマートフォン・タブレット・PCなど、
画面サイズに応じてレイアウトが切り替わるように実装しています。

---

### ナビゲーションメニュー

ユーザーが各セクションへ移動しやすいよう、
シンプルなナビゲーションを実装しています。

---

### ビジュアルデザイン

カフェの落ち着いた雰囲気を表現するため、

* 配色
* 余白
* フォント
* 写真配置

などを意識してデザインしました。

また、ページ遷移を少なくし、ほとんど１ページで完結するような構成にしました。

---

### アニメーション

hover アニメーションやスクロール表現などを取り入れ、
サイトに動きを加えています。

---

## 工夫した点

### ① チーム開発

7人チームで制作を行ったため、

* 役割分担

* コミュニケーション

を意識しながら開発を進めました。

---

### ② クライアント視点を意識した制作

講師がクライアント役となっていたため、

* 要件に沿った制作

---

### ③ レスポンシブデザイン

スマホでのアクセスが多いことを考慮して、

などを画面幅に応じて変更しています。
